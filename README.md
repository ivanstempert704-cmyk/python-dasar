## 🚀 How to Run the Code

1. **Ensure Python is installed** on your system (Python 3.x recommended):
   ```bash
   python --version
   ```

2. **Clone this repository:**
   ```bash
   git clone https://github.com/ivanstempert704-cmyk/python-dasar.git
   cd python-dasar
   ```

3. **Activate the Virtual Environment** (Optional, but recommended):
   * **Windows:**
     ```bash
     venv\Scripts\activate
     ```
   * **Linux/Mac:**
     ```bash
     source venv/bin/activate
     ```

4. **Navigate to the source folder and run any Python script:**
   ```bash
   cd python-dasar
   python pakage.py
   ```
   *(Replace `pakage.py` with any other file you wish to run)*

## 📚 Topics Covered
* **Fundamentals:** Basic syntax, variables, constants, data types, and operators (`hello.py`, `variable.py`, `tipe-data.py`, `operator.py`).
* **Control Flow & Data Structures:** Conditionals, loops, lists, and dictionaries (`control-flow.py`, `list.py`, `dictionary.py`).
* **Functions, Modules & Packages:** Modular programming using functions, custom modules, custom packages (`my_package`), and built-in libraries like `os` and `datetime` (`function.py`, `module.py`, `pakage.py`).
* **File & Error Handling:** Reading/writing `.txt` files and handling runtime errors (`file-handling.py`, `exeption.py`).
* **Object-Oriented Programming (OOP):** Classes, objects, encapsulation, inheritance, polymorphism, and abstraction (`class.py`, `encapsulation.py`, `inheritance.py`, `polymorphism.py`, `abstraction.py`).
